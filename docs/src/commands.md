# Command reference

> Generated by `make commands-doc` from the `Makefile`.
> Do not edit by hand — re-run `make commands-doc` after changing a target.

Caller and Mode come from the `| caller=.. | mode=..` tag on the target's `## `
help line in the Makefile (n/a where a target carries no tag, e.g. build/test
utilities). Mode lists which `OUTPUT_MODE` values the target accepts; n/a means
the target does not broadcast, or broadcasts unconditionally as EOA.
